# ЛР5. Форма и список в памяти

| Проверка | Что делаю | Факт |
|---|---|---|
| Успех | title ≥ 5, laboratoryId > 0, description ≥ 10 | строка со статусом New появилась в списке |
| Отказ | title = abc | под полем ошибка, строка не добавлена |
| Память | F5 после успешного создания | добавленная строка исчезла (ожидаемо: сервера и БД пока нет) |

Поле laboratoryId хранится числом (v-model.number). Форма отправляется через @submit.prevent, поэтому Enter не перезагружает страницу.
